# inputs/miro/ - イベントストーミング結果（Miro）

Miroで実施したイベントストーミング（カラーパズル）の結果を取り込んだ生データ。
要件定義ドキュメント（[../../README.md](../../README.md) 7章ほか）はこの内容を元に作成している。

## ファイル構成

- `miro-event-storming.csv`: イベントストーミングの付箋（イベント／コマンド／アクター／集約等）のテキストエクスポート。**本体データ**。検索・grep対象はこちら。
- `miro-event-storming_all.png`: ボード全体の俯瞰スクリーンショット（縮小・全コンテキスト配置の確認用）。
- `miro-event-storming_1.png` 〜 `_10.png`: ボードを分割したスクリーンショット（CSVの文字情報を読みづらい場合の図解参照用）。画像内のテキストは縮小されているため、内容確認は基本的にCSVを使う。

## 画像とコンテキストの対応（目安）

| 画像 | 主な内容 |
|---|---|
| `_1` | 認証コンテキスト、アカウントコンテキスト（ログイン申し込み〜未登録アカウント） |
| `_2` | アカウントコンテキスト（本登録・停止・停止解除） |
| `_3` | アカウントコンテキスト（権限変更ほか） |
| `_4` | メッセージコンテキスト |
| `_5` | 星取表コンテキスト（マスタ登録・更新・アーカイブ） |
| `_6` | 星取表コンテキスト（ユーザーの星取表登録・更新） |
| `_7` | 星取表コンテキスト終盤、経歴書コンテキスト開始 |
| `_8` | 経歴書コンテキスト、ファイルコンテキスト |
| `_9` | キャリアシートコンテキスト前半 |
| `_10` | キャリアシートコンテキスト後半 |
| `_all` | 全体俯瞰図 |

画像の分割範囲はスクリーンショット時のスクロール位置に依存するため、上記は目安（隣接画像と内容が重複する場合がある）。
